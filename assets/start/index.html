Add a computer

On the computer, open Forge, then Devices, Phones. Turn on the phone link and choose Show a pairing code. This device and the computer must be on the same Wi-Fi.

Scan the picture under the code with the camera, paste the pairing link, or type what Devices shows.

The check code proves the address is your computer: the app trusts its certificate only when they match, and nothing is sent before that. Only home-network addresses are used.
